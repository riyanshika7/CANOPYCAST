# CanopyCast Frontend

React frontend visualizing urban heat islands and optimal tree-planting green corridors using Leaflet.js.

## 🚀 Setup & Installation

1.  **Install Node dependencies:**
    ```bash
    npm install
    ```

2.  **Run Development Server:**
    ```bash
    npm run dev
    ```
    The application will run locally at `http://localhost:5173`.
