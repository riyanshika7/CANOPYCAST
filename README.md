# CanopyCast: Hyper-Local Urban Heat & Green-Corridor Planner

CanopyCast is a map-based planning tool designed to analyze the Urban Heat Island (UHI) effect and optimize native tree planting locations to maximize cooling and wildlife corridor connectivity.

## 📁 Repository Structure

*   `backend/` - FastAPI backend, SQLite database, RAG pipeline, and optimization engine.
*   `frontend/` - React frontend with Leaflet.js map visualization and Tailwind CSS.

## 🛠️ Tech Stack
*   **Frontend:** React, Tailwind CSS, Leaflet.js, Recharts
*   **Backend:** FastAPI, Python, SQLite, LangChain (ChromaDB / FAISS)
*   **Deployment:** Docker, Render/Railway, Vercel

## 🚀 Getting Started
Refer to the README files inside the `/frontend` and `/backend` directories for specific setup instructions.
